# Authentication — Engineering Pack

_Domain: **authentication**_

Authentication and session handling: password hashing, MFA, sessions/JWT, lockout, OAuth/OIDC.

> **Scaffold** — structured starting point seeded with real domain bullets. Expand the sections for your project.

## What this pack provides
- **Policies** — enforceable rules for this domain (`policies.md`).
- **Checklists** — review gates (`checklists.md`).
- **Patterns** — recommended approaches (`patterns.md`).
- **Architecture** — structural guidance (`architecture.md`).
- **Context** — the distilled brief fed to agents (`context.md`).
- ADRs, templates and examples under `adr/`, `templates/`, `examples/`.

Install into a project with `nxai pack add authentication`; the Pack Provider then feeds its policies/checklists/context to the agents working in this domain. This pack contains **no code and no AI** — it organizes knowledge so the model applies it correctly.
