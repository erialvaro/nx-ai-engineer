# Example — Repository Standards

Running `nxai scaffold --stack python`
in a fresh repo adds `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `.editorconfig`,
`.github/ISSUE_TEMPLATE/*`, `.github/PULL_REQUEST_TEMPLATE.md`, `.github/workflows/ci.yml`
(Python) and a `.gitignore` — skipping any file that already exists.
