# Contributing

Thanks for contributing! A few conventions keep the project healthy.

## Workflow
1. Open an issue describing the change.
2. Branch from `main`; keep branches short-lived.
3. Add tests and docs for your change.
4. Ensure CI is green and open a PR using the template.

## Standards
- Follow the existing style and structure.
- No secrets in the repo.
- Keep the CHANGELOG updated; we use Semantic Versioning.

## Code of Conduct
By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
