# ADR-0001: Containers / Docker baseline

- **Status:** Accepted
- **Domain:** containers

## Context
Container image and runtime best practices: minimal, non-root, reproducible, secret-free, scanned.

## Decision
Adopt the policies and patterns in this pack as the domain baseline.

## Consequences
Changes in this domain are reviewed against `checklists.md`; violations of `policies.md` block delivery.
