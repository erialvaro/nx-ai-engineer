# Checklist — LGPD / Privacy

Review gate for changes touching this domain.

- [ ] PII inventory updated for the changed data flow
- [ ] Lawful basis documented for new/changed processing
- [ ] PII encrypted at rest and in transit
- [ ] Access restricted by least privilege and tenant scope
- [ ] Logs/telemetry/errors contain no raw PII
- [ ] Retention/purge path exists for the new data
- [ ] Deletion (right to be forgotten) path covers the new data
- [ ] Export (portability) path covers the new data
- [ ] Consent captured/withdrawable where required
- [ ] DPIA done if processing is high-risk
- [ ] Processor DPAs and transfer safeguards in place
- [ ] Incident/breach runbook covers this data
