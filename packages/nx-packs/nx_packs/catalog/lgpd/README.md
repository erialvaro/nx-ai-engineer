# LGPD / Privacy — Engineering Pack

_Domain: **privacy**_

Brazilian LGPD and general privacy/PII handling: lawful basis, data-subject rights, minimization, tenant isolation, retention and incident response.

## What this pack provides
- **Policies** — enforceable rules for this domain (`policies.md`).
- **Checklists** — review gates (`checklists.md`).
- **Patterns** — recommended approaches (`patterns.md`).
- **Architecture** — structural guidance (`architecture.md`).
- **Context** — the distilled brief fed to agents (`context.md`).
- ADRs, templates and examples under `adr/`, `templates/`, `examples/`.

Install into a project with `nxai pack add lgpd`; the Pack Provider then feeds its policies/checklists/context to the agents working in this domain. This pack contains **no code and no AI** — it organizes knowledge so the model applies it correctly.
