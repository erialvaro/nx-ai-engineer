# ADR-0001: Billing / Payments baseline

- **Status:** Accepted
- **Domain:** billing

## Context
Money handling: idempotency, integer cents, audit trail, webhook verification, reconciliation.

## Decision
Adopt the policies and patterns in this pack as the domain baseline.

## Consequences
Changes in this domain are reviewed against `checklists.md`; violations of `policies.md` block delivery.
