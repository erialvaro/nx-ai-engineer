# PostgreSQL — Database Engineering Pack

_Category: **database**_

Relational data modeling and PostgreSQL engineering: normalization, relationships, indexing strategy, query performance (EXPLAIN/cost) and safe migrations.

## What this pack provides
- **policies** (rules) · **checklists** · **patterns** · **anti-patterns** ·
  **performance** · **security** — the engine's reusable engineering knowledge.
- Templates, examples and an agent **prompt** under `templates/`, `examples/`, `prompts/`.

Install with `nxai pack add postgres`. It auto-attaches (via `applies_to`) to the
Database / Relational / NoSQL / Reviewer agents — the **same knowledge, many agents**.
Contains **no code and no AI**: the agent reasons; the pack organizes the knowledge.
