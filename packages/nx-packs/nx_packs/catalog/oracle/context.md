# Context — Oracle

Engineering standard for Oracle. Relational modeling on Oracle: partitioning, indexing, cost-based plans.

## Non-negotiables
- Reuse entities.
- Validate normalization + cardinality.
- Justify indexes; check the CBO plan.

## Always verify
- 1NF/2NF/3NF
- PK/FK/Unique
- Indexes
- Plan/cost validated
- Migration reversible
