# ADR-0001: Cloud Architecture baseline

- **Status:** Accepted
- **Domain:** cloud

## Context
Cloud architecture and operations: IaC, least-privilege IAM, network segmentation, secrets, backups, resilience.

## Decision
Adopt the policies and patterns in this pack as the domain baseline.

## Consequences
Changes in this domain are reviewed against `checklists.md`; violations of `policies.md` block delivery.
