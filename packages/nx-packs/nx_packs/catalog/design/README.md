# Design System & UI/UX — Engineering Pack

The knowledge standard for interfaces that are **beautiful, usable, accessible and
fast** — and for shipping a **design system** the `frontend` agent can implement
without guessing. Feeds the **`designer` agent** (and `frontend`) via the
Engineering Contract, alongside the **`seo` pack** (design moves Core Web Vitals).

## What it covers
- **[design-system.md](design-system.md)** — tokens as the single source of truth.
- **[typography.md](typography.md)** — type scale, pairing, measure, hierarchy.
- **[color.md](color.md)** — palette roles, contrast, light **and** dark.
- **[layout-spacing.md](layout-spacing.md)** — spacing scale, grid, responsive.
- **[accessibility.md](accessibility.md)** — WCAG 2.2 as a **gate**, not a wish.
- **[motion.md](motion.md)** — a motion system with **framer-motion** (+ reduced-motion).
- **[tooling.md](tooling.md)** — `ui-ux-pro-max`, the **21st.dev** CLI family,
  shadcn/Tailwind, `dataviz`, framer-motion.
- **[patterns.md](patterns.md)** / **[anti-patterns.md](anti-patterns.md)** — do / never-do.
- **[architecture.md](architecture.md)** — design → frontend handoff.
- **[context.md](context.md)** — the compact brief injected into the agent.

## The bar
Design is done when it is **consistent** (tokens, no magic values), **accessible**
(WCAG in light *and* dark), **implementable** (a spec, not a vibe), **fast** (no
CWV regression) and **complete** (loading/empty/error states — not just the happy path).

Packs are **knowledge only** — no code, no execution.
