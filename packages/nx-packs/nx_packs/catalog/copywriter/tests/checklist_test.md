# Copy quality gate (evidence required)

Every piece must pass before it ships.

## Human voice
- [ ] AI-tells / cliché screen passes (`anti-patterns.md`) — zero hits
- [ ] Sentence rhythm varies; active voice; concrete specifics; a real POV
- [ ] Reads naturally aloud (no press-release / bot cadence)

## Accuracy
- [ ] Every spec / number / benchmark / quote is **verified** (source noted)
- [ ] No fabricated capabilities or stats
- [ ] Terminology precise and current for the audience

## Persuasion
- [ ] One hook; one idea per section; one primary CTA
- [ ] Claims paired with proof; a fitting framework applied

## SEO (with the `seo` pack)
- [ ] Search intent matched
- [ ] Primary term naturally in title / H1 / first paragraph; no stuffing
- [ ] Answer-first opening; descriptive H2/H3; intentional internal links
- [ ] Title (~50–60) + meta description (~150–160) supplied

## Deliverable completeness
- [ ] Copy + title + meta description
- [ ] Framework + primary keyword/intent documented
- [ ] Any unverifiable claim flagged, not shipped

Ship only when every applicable box has **evidence**, not assumption.
