# ADR-0001 — Copywriting baseline (human, accurate, SEO-ready)

- **Status:** Accepted
- **Context:** Tech/innovation audiences are skeptical and expert. Copy must read
  like a knowledgeable human wrote it, be technically accurate, persuade toward one
  action, and rank in search + AI answers — not read like generic AI output.

## Decision
Adopt this pack's standard for all marketing/content copy:
- **Human voice** — varied rhythm, active voice, specifics, a real point of view;
  the `anti-patterns.md` AI-tells screen is mandatory.
- **Truth** — no fabricated specs/metrics/quotes/capabilities; verify or omit.
- **Domain fluency** — precise, current tech terminology; write for the real reader.
- **Persuasion** — one hook, one idea per section, one CTA, a fitting framework.
- **SEO** — intent-matched, answer-first, primary term in title/H1/intro, title +
  meta description supplied; clarity wins over keyword density (pairs with the
  `seo` pack).

## Consequences
- ➕ Copy is credible to a technical audience and built to rank/be cited.
- ➕ Quality is checkable (AI-tells screen, fact verification, SEO checklist) — not
  a matter of taste alone.
- ➖ Requires a brief per piece and a disciplined self-edit loop; enforced via the
  `copywriter` agent's checklist and this pack's `policies.md` / `anti-patterns.md`.
