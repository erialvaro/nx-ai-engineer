# Copywriting checklist

## Brief (before writing)
- [ ] Audience + awareness stage defined
- [ ] Goal + single primary CTA defined
- [ ] Primary keyword + search intent defined
- [ ] Voice/tone + language (PT-BR / EN) set
- [ ] Proof points gathered (verified facts, numbers, sources)
- [ ] Format + length agreed

## Human voice
- [ ] Varied sentence rhythm (not uniform); active voice
- [ ] Concrete specifics, not abstractions; a real point of view
- [ ] Reads well aloud; sounds like a person, not a bot/press release
- [ ] **AI-tells / cliché screen passes** (`anti-patterns.md`)

## Accuracy (tech)
- [ ] Every spec/number/benchmark/quote is **verified** (nothing invented)
- [ ] Terminology precise and current for the audience level
- [ ] Claims are true and, where strong, sourced

## Persuasion & structure
- [ ] One hook that earns attention; one idea per section
- [ ] Scannable subheads; skimmable; logical flow (a fitting framework)
- [ ] Exactly one primary CTA, clearly worded

## SEO (with the `seo` pack)
- [ ] Search intent matched
- [ ] Primary term naturally in title, H1, and first paragraph
- [ ] Descriptive H2/H3 mirroring real questions; answer-first opening
- [ ] Intentional internal links; no keyword stuffing
- [ ] Title (~50–60) + meta description (~150–160) supplied

## Final self-edit
- [ ] Cut throat-clearing, filler, and hedging
- [ ] Replaced vague words with specifics
- [ ] Trimmed ~10–20% for punch; every sentence earns its place
