# Context — SQL Server

Engineering standard for SQL Server. Relational modeling on SQL Server: indexing, execution plans, migrations.

## Non-negotiables
- Reuse entities; no duplicate tables.
- Validate normalization.
- Justify indexes; check the plan.

## Always verify
- 1NF/2NF/3NF
- PK/FK/Unique
- Indexes
- Execution plan validated
- Migration reversible
