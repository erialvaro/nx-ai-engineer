# Historical reports

Point-in-time audit and release reports from earlier phases of the project
(pre-1.0 development: the `AIES 5.0.0-rc1` era and the monorepo migration). They
are kept for provenance and **describe the layout/version at the time of
writing** — they are not current documentation.

For current docs see the top-level [README](../../README.md), the
[CHANGELOG](../../CHANGELOG.md), and the bundled guides under
`packages/nx-cli/nx_cli/_template/docs/` (also available via `nxai docs`).
